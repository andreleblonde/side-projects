# Side Projects

## Projects

### AI Side Project Generator
Web app that generates side project ideas based on your interests and skills.

**Location:** `side-project-generator.html`

**To run:**
```bash
node /Users/andreleblonde/.openclaw/server.js
# Open: http://localhost:3456/side-project-generator.html
```

## Configuration

- Voice transcription: OpenAI Whisper (local)
- API: MiniMax (Kimi K2)
- Model: MiniMax-M2.1
